# OpsPilot-AI 标准工作流程

本文件供新会话直接阅读。每个流程都可从仓库代码和对应手册执行。

| 场景 | 从哪里开始 | 操作与验收 |
| --- | --- | --- |
| 接手需求 | [AGENTS.md](../AGENTS.md)、[实施计划](IMPLEMENTATION_PLAN.md) | 查看分支、工作区和受影响模块，确认当前需求，再按范围、文件、兼容性、风险和验收列计划。 |
| 改接口或页面 | `opspilot_api/opspilot_api/apps/`、`opspilot_web/src/` | 先读相邻实现和测试，沿用 API、权限和界面组件。检查正常、越权和失败路径，复测对应页面。 |
| 告警、诊断与修复 | [诊断工作流](DIAGNOSTIC_WORKFLOW.md) | 准备隔离告警，采集证据，核对适用动作和审批人，验证失败、去重及复检。生产动作需要针对目标授权。 |
| 作业与发布 | [受控作业](MANAGED_JOBS.md)、[发布和恢复](RELEASES_AND_RECOVERY.md) | 用测试主机和只读模板检查队列，再用已授权测试服务验证制品摘要、独立审批、首批、停止和回退。 |
| 监控与样例 | [监控手册](MONITORING.md)、[模块示例](MODULE_EXAMPLES.md) | 检查 Prometheus 采样、同步器心跳和告警更新。需要展示时，先在隔离库创建示例。 |
| 截图与 GitHub | [验证与上线](VERIFICATION_AND_RELEASE.md) | 使用演示账号及保留地址截图。检查每张图、待提交文件和目标分支，提交后核对远程分支和页面链接。 |
| 容器发布 | [部署说明](DEPLOYMENT.md) | 核对目标、备份和活动任务，构建后检查迁移、服务状态、登录、执行器和监控，记录版本及回退方式。 |
