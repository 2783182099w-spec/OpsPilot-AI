# 轻量运维与验收功能

目标是单 API、单执行器、少量运维人员管理几十到几百台授权服务器。保留 Django/Vue 和现有 SSH，不安装 Agent，不引入 Celery、会话录像或持续高频采集。当前无需 Redis；多 API 实例、多执行器和跨进程会话管理需要重新设计并验证后再启用。

本地默认启动已构建前端的静态预览，避免常驻 webpack 开发服务。修改前端后先 `pnpm run build`；需要热更新时用 `scripts/start-local.ps1 -FrontendMode dev`。本地预览服务器只绑定回环地址，不作为生产部署服务器。

## 功能入口

- **资产管理**：环境、业务、负责人、系统版本、用途、人工生命周期状态；按环境与 SSH 端口状态筛选；详情及字段变更记录；文件传输。
- **巡检与验收**：选择授权主机，执行 SSH 端口检测、资源健康、Linux 基线与验收检查。定时计划、模板版本和异常处理在同页不同标签中。
- **任务中心**：查看执行器心跳、逐台状态和有限长度输出，取消、人工确认重试失败主机，下载 CSV 报告。结果详情每页 20 台。
- **AI**：保持现有辅助框，输入日志或报错，获得可能原因和排查建议，不执行命令。本轮未增加知识库、自动修复或复杂 AI 工作流。

## 资源预算与限制

| 项目 | 当前限制 |
| --- | --- |
| 单任务资产数 | 最多 300 台 |
| 同时执行的 SSH 检查/命令 | 最多 4 台，只有 4 个在途 future，不为每台主机创建线程 |
| 排队限制 | 每人最多 5 个任务，全局待处理最多 100 个；计划不叠加未完成任务 |
| 单台命令时限 | 60 秒，连接、认证阶段另有超时 |
| 收集输出上限 | 普通命令 64KiB，巡检 128KiB；单台展示和保留的原始输出最多 16KiB |
| 计划周期 | 15 分钟到 7 天，默认 60 分钟，创建后默认停用 |
| 调度轮询 | 空闲约每 2 秒检查数据库，无独立调度服务 |
| 执行器租约 | 30 秒；活跃执行器不会被第二个实例抢占 |
| Web SSH | 单 API 进程最多 12 个终端；空闲 15 分钟或 Token 过期关闭；不录制屏幕 |
| SFTP | 单进程最多 2 个传输；单文件 10MiB；传输阶段 60 秒；大于 512KiB 的下载临时内容落盘 |
| 页面刷新 | 活跃任务且页面可见时每 5 秒刷新；空闲页面不持续轮询任务历史 |

这些是代码限制，不是已完成真实 300 台服务器容量压测的结论。后端测试使用 300 个虚拟资产和模拟 SSH 验证并发上限及结果完整性；真实资源占用、网络延迟和不同 Linux 环境仍需授权测试。
单个终端的转发输出限制约 128KiB/s，避免大量输出持续占满浏览器与网络。

## 检查内容与边界

资源检查包含 CPU 短时采样、内存、磁盘、负载和系统版本；基线增加 UID 0 账号、shadow 文件权限、SSH root/密码策略、时间同步、常见防火墙服务、关键软件版本和 dnf 本地缓存安全公告。验收可附加最多 10 个 systemd 服务及 5 个证书文件。

检查不读取 shadow 内容，不修改 SSH、账户、防火墙或软件包配置，不刷新软件源或执行漏洞利用。
无权限、缺命令、无数据、输出不完整均标为 unknown，不能当作通过。版本信息和缓存公告不能证明没有漏洞；需结合发行版补丁及公告人工复核。
端口可达只表示 TCP 可连接，不代表系统或业务健康，始终结合最后检测时间使用。

## 任务恢复、取消与重试

执行器领取数据库租约并心跳续期。另一个执行器不得打断活跃任务。旧租约过期后，遗留任务与未完成主机标为 interrupted，不会自动重跑变更命令。进程硬退出后重新启动可能等待旧租约最多约 30 秒。

取消排队任务不建立连接；取消运行任务停止后续派发并关闭 SSH 通道。关闭通道、超时或失联不能保证远端命令已经终止。重试必须人工确认远端状态，只重新提交未成功主机；普通用户的命令仍需审批。

## 模板与定时计划

管理员维护模板及版本、变更说明和参数定义。示例：命令 `systemctl status {{service}}`，参数定义：

```json
[{"name":"service","type":"enum","choices":["nginx","sshd"],"required":true}]
```

参数作为独立 shell 参数引用；不允许带参数的模板包含引号、变量展开或反引号，避免不明确的拼接语义。模板仍属于可信管理员代码，不能仅靠 shell 转义判断所有命令语义安全。不要通过参数传密码或密钥。

定时计划只允许固定的只读巡检和端口检测，不能定时执行任意命令。页面当前创建巡检计划；端口计划可通过同一 API 使用 kind=probe 创建。启用计划才会连接资产，权限失效后自动停用，不补跑积压的历史周期。

## 异常处理与外部告警

巡检异常按用户、主机、检查项归并，重复出现更新证据；后续同项检查通过时自动恢复。支持确认、指派负责人、处理说明与关闭记录。
外部工具可使用现有 JWT 认证调用 `POST /host/findings`，提供 host_id、稳定 event_id、title、evidence、state（open/resolved），只允许已授权资产；没有开放匿名 webhook。该接口不发送邮件或第三方消息。

## SFTP

默认读取范围为 `/tmp`、`/var/log`，写入只允许 `/tmp`。可在私有配置使用 SFTP_READ_ROOTS、SFTP_WRITE_ROOTS 缩小或调整范围。检查规范化路径，拒绝目录穿越和逃逸符号链接；仅传普通文件。
上传使用临时文件，成功后重命名；覆盖需要明确确认及服务器支持 posix-rename，不先删除旧文件。失败清理仅针对本次上传创建的临时文件。展示内容 SHA256，下载也检查文件是否在传输期间变化。
读取目录最多展示 200 项。传输历史查询不连接远端。没有远端文件删除功能。

## 本轮验证与后续

先在本地完成迁移、模拟 SSH/文件系统测试、前端构建及浏览器检查；不会自动接触现有真实资产。按本轮新增需求提供有界的文本回放，不实现录像和原始交互时序还原。容器化、生产部署和本轮 GitHub 上传均留待用户另行授权。

后端验证命令：`python manage.py test host mtask ai`。本地浏览器验收可选用 `.venv/Scripts/python.exe scripts/smoke-operations.py`，需要 Node.js、Playwright 及本机 Edge；它自动创建并清理临时本地数据，不执行任务、不建立 SSH/SFTP 连接。Playwright 不属于应用运行依赖。


## 2026-10-22：使用流程与文本记录完善

- 巡检页展示资源健康、安全基线、验收三个方案的具体范围，支持名称/IP/业务筛选。提交后直接进入报告。
- 任务中心按类型、状态、提交人/命令/ID、日期筛选，服务端每页 20 条。检查报告汇总通过、异常、待确认、需复核数量，可按主机执行状态、名称/IP、检查结论筛选；执行成功不等于检查通过。报告导出仍包含完整结果。
- 定时计划独立选择资产，支持编辑检查内容、间隔、首次执行时间，以及立即检查、启停、删除和最近任务跳转。每天/每周是固定间隔，不是 cron 日历时间；上轮未结束时跳过、不补跑。立即执行不更改启停状态和下一次时间。
- 命令模板提供只读服务查询示例和参数表单，不再要求手写 JSON。后端保存时验证参数与占位符，执行前必须预览最终命令并再次确认。模板修改保留旧版本，普通用户命令仍需要审批。
- 异常可按状态、级别和关键词筛选，关联来源报告，保留处理记录、负责人，支持确认后复查原方案；通过项自动关闭对应异常，再次失败重开。外部告警不因端口检测通过而自动关闭。
- CMDB 以绿色/红色/灰色表示最近 SSH TCP 端口可达/不可达/未检测，显示检测时间说明，并提供检测本页入口。不是持续心跳监控，也不将认证失败误判为主机关机。
- 任务中心新增 SSH 文本记录：仅保存升级后会话的远端输出，不记录原始键盘输入。Shell 回显的命令可在文本中查看，但不声称这是准确的逐命令审计；全屏应用的文本效果也不会完全还原。
- 文本回放支持逐行播放、暂停、速度选择、全文和下载，不恢复原始交互时序。每会话最多 256 KiB，按最近 1000 个会话或 30 天限制可见文本，新连接时清理到期文本并保留元数据。列表不携带正文，每 5 秒最多保存一次会话文本，关闭时补存。
- 文本去除终端控制序列并对常见凭据及私钥块脱敏，不能识别任意格式的机密内容，请勿在终端显示凭据；关闭回显的密码输入不写入记录。普通用户只能查看自己的会话，且仍须持有目标主机权限，管理员可查看所有记录。

本轮数据库增加来源任务关联及会话文本字段；迁移前保留了本地 SQLite 备份。此前会话没有文本，不能补生成回放。不增加 Redis、录像、Agent 或新的常驻服务。
