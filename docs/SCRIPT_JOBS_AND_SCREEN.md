# 批量脚本作业与运维态势大屏

## 本轮用途

批量作业支持短命令、Shell 脚本和 Python 3 脚本。脚本库保存可复用源码与版本，任务保存提交时的不可变快照；已经提交的任务不会因脚本库后续编辑而改变。

展示中心升级为运维态势大屏，汇总当前账号有权查看的资产、采集、告警与任务，不填写虚构的在线率或健康分。监控与告警依赖前一阶段已接入的 Prometheus，本轮没有新增常驻服务、Redis 或任务队列组件。

## 脚本执行流程

```mermaid
flowchart LR
 A[粘贴或导入 .sh/.py] --> B[选择授权主机与位置参数]
 B --> C[文本检查与签名预览]
 C --> D[人工确认]
 D --> E[普通用户审批 / 管理员排队]
 E --> F[受限并发连接 SSH]
 F --> G[随机临时目录投递源码]
 G --> H[摘要和远端语法检查]
 H --> I[timeout 执行解释器]
 I --> J[逐主机结果与审计]
 J --> K[清理投递源码与空目录]
```

### 编辑与导入

- Shell 使用远端 `bash`；Python 使用远端 `python3`，不是 Windows 本机 Python，也不依据 shebang 随意切换解释器。
- 可直接编辑或导入 UTF-8 `.sh` / `.py`，最大 64 KiB。后台统一去除 UTF-8 BOM 并将换行规范化为 LF。
- Python 先在平台进行 AST 语法检查，不运行用户代码；执行前还会用远端解释器再次检查。两端版本不一致时，以远端兼容性为准。Shell 在远端执行 `bash -n` 后才运行。
- 位置参数最多 20 个，单个最多 500 字节、合计最多 4000 字节，不允许控制字符。Shell 用 `$1` 等读取，Python 用 `sys.argv[1]` 等读取。
- 不把参数替换进源码。命令行参数逐个进行 shell quoting；分号、空格、引号或 `$()` 只是参数内容，不应被解释为额外命令。
- 平台不安装 pip 包、不自动调整远端 Python 环境。缺少解释器或依赖时，该主机失败并返回原因，其他目标继续。

### 预览与权限

预览绑定规范化的源码、参数、名称、解释器、超时、并发与完整目标集合，签名有效期 10 分钟。任意这些内容或目标发生变化必须重新预览。预览本身不连接远端主机。

提交和执行阶段都检查主机权限；审批时再次核查任务所有者对目标的权限。普通用户任务进入待审批；管理员预览确认后进入队列。脚本与命令沿用同一套用户任务隔离、执行器租约、取消和历史结果。

脚本不是沙箱，实际权限就是 SSH 连接账号的权限。以 root 连接的脚本可以执行 root 允许的操作。平台不会声称语法检查、预览或字符串转义能够判断脚本是否安全。

任务中心展示完整任务源码（常见敏感字段做展示脱敏）、语言、名称、脚本库版本、SHA256、参数、并发、超时、每台主机状态、退出码和输出。审批和重试脚本时读取完整快照供审核，列表只给出源码摘要，不在列表反复传输大正文。

### 投递与资源控制

- 每台主机创建 `/tmp/opspilot-job.<随机值>`，目录权限由 `umask 077` 和 `mktemp -d` 控制；投递源码权限为 0600。
- 源码通过 SFTP 写入独立文件，不拼接进 shell heredoc 或命令字符串。执行前校验远端 SHA256，防止投递内容与快照不符。
- 脚本工作目录是该随机临时目录。不要依赖 SSH 用户家目录作为当前目录；需要访问的数据应使用明确路径或位置参数。
- 脚本默认并发 2 台，可选 1～4 台；单批沿用最多 300 台、每人最多 5 个待执行任务和全局队列上限。
- 单机脚本执行时间为 5～600 秒，依赖远端 GNU/coreutils `timeout`。连接、投递、语法检查和清理有各自超时，不包含在脚本主体时限内。
- stdout/stderr 合并，远端执行输出上限 64 KiB，数据库保留受限预览和结果。输出超限或异常时保留最后一段已收到的输出，避免只有一句错误而无法定位。
- 返回 124 通常表示 `timeout` 超时，137 表示被强制终止；脚本自身也可能使用相同退出码，必须结合输出判断，不能单凭退出码推断所有原因。
- 用户取消会停止继续派发并关闭通道。远端 timeout 尽力终止进程组，但脱离进程组的后台进程或特殊子进程不保证终止。重试前必须核实远端状态。
- 使用远端 EXIT trap 和平台 finally 双层尽力清理投递的源码及空目录，不递归删除。脚本生成的其他文件会留在受限目录，并在可判断时提示路径；业务脚本应自行管理产物。

### 脚本库

管理员可以保存、修改和归档脚本；修改要求提交期望版本，避免覆盖他人的新版本。历史版本保留源码和说明，归档不删除已经提交任务的快照。

脚本库是共享代码库，载入时保持源码原样，避免自动替换导致代码语义变化；不要把密码、Token 或私钥写入源码。预览和任务展示会对常见敏感字段做脱敏，但不能自动识别所有机密。凭据应通过后续受控凭据机制或远端既有配置使用，不能依赖源码分发。

失败重试使用原任务快照，保留原解释器、参数、并发与超时；重新核对主机权限，普通用户仍需再次审批。不自动改成脚本库的最新版本。

### API

- `POST /mtask/scripts/preview`：预览并获得签名；传 `host_ids` 与 `script`。
- `GET/POST /mtask/scripts`、`GET/PATCH/DELETE /mtask/scripts/<id>`：脚本库和版本。
- `POST /mtask/tasks`：`kind=script`，传 `script`、`preview_token`、`host_ids`、`confirmed=true`。
- 位置参数、超时、并发都在 `script` 对象内。既有命令、巡检、在线检测 API 不变。
- 脚本不会加入当前只读定时巡检调度，避免将任意修改脚本作为周期任务自动运行。

## 大屏的数据口径

- 授权资产：当前账号 CMDB 权限范围内的资产。
- 采集正常：当前摘要中成功采集、样本未过期且没有 collector 失败的目标。不等于所有业务健康。
- 失联 / 异常采集：端点失联、数据未知、过期及部分 collector 失败；不把未接入资产标为离线。
- 触发中的告警：当前用户可见告警中故障状态仍为 active 的数量，另外显示严重和未知数量。
- 任务成功率：近 24 小时提交、状态为 completed / failed / interrupted 的任务中，completed 占比。取消、待审批、运行中不进入分母；没有已结束任务时显示横线。
- 资源趋势：当前授权采集目标近一小时的 CPU、内存算术平均，不按核数或内存容量加权；缺失点不补零，旁边注明有效样本数。
- TOP 5：仅使用最近有效采样；磁盘是最高文件系统使用率，不是整台主机平均磁盘使用率。
- 资产环境分布：来自 CMDB 标签；近期告警与作业可跳转对应处理页面。

监控摘要上限沿用 300 台。资产总数可超过此值，界面会提示摘要范围，避免将部分采集数量展示成全量覆盖。

大屏默认隐藏资产标识，可手动切换。它主要隐藏资产名称和地址，不承诺对用户自定义告警标题中可能嵌入的业务信息全面脱敏。截图或对外展示前仍应检查。

支持浏览器全屏与窗口沉浸模式，退出或离开页面时释放图表和监听器。每 30 秒刷新，后台标签页暂停刷新；图表关闭动画、限制样本数量，不使用高频粒子或持续重绘装饰。

## 验证边界

关键逻辑包含权限、签名防篡改、脚本版本、重试快照、参数传递、输出限制和临时目录校验等测试。Windows 本地存在 Git Bash 时，使用真实 Bash、coreutils timeout 与项目 Python 进行本地执行测试，覆盖两种语言、参数字面值、语法错误、超时和临时文件清理；这不是对所有 Linux 发行版的 SSH 端到端验证。

本轮不会向云主机发送任意测试脚本。浏览器测试用临时普通用户提交脚本，确认处于待审批后取消，不批准执行。正式使用前建议先选择授权测试主机、使用库中的只读示例进行小批验证，再扩大目标范围。
