# OpsPilot-AI 实施计划

更新于 2026-11-11。项目面向几十到几百台 Linux 主机。后端为 Django、DRF、Channels 和 Paramiko，前端为 Vue 3 和 Ant Design Vue。

## 当前基线

| 范围 | 当前能力 | 下一次验收 |
| --- | --- | --- |
| 账号与资产 | 管理员、运维员、观察员，主机授权、资产管理、会话记录与撤销 | 授权 Linux 主机上的可信指纹、SFTP、授权撤回和断线释放 |
| 巡检与作业 | Shell、Python、受控作业、分批执行、历史结果、巡检报告和定时检查 | 批量超时、取消和主机状态未知时的结果一致性 |
| 监控与告警 | Prometheus、Node Exporter、HTTP 探测、告警队列和待审批 | 指标缺失、探测中断、恢复确认和告警收敛 |
| 诊断与修复 | 诊断目录、自建树、联动、结果、独立审批。受控动作包括 Nginx 启动与测试资产 SSH 基线修复 | 在明确授权的测试机验证实际修复、回退和登录可用性 |
| 发布流水线 | 应用登记、制品上报、SSH 预检、审批、首批、分批和回退 | 真实测试制品发布、首批停止、回退及服务验证 |
| AI 助手 | 默认模型和个人密钥配置，日志和故障分析 | 真实模型调用、脱敏与用量验收。告警证据直送 AI 的流程已讨论，尚未实现 |

Alibaba Cloud Linux 3 上已运行 Compose 版本，容器后端使用 Python 3.12。浏览器登录和真实采样已验证，详细状态见 [验证与上线](VERIFICATION_AND_RELEASE.md)。提交记录、当前工作区和运行版本可能不同，开始前先核对。

## 后续顺序

1. **对齐本次需求与基线**。读取五个交接文件，检查当前分支、工作区差异和目标环境，给出本次改动和验收计划。
2. **优先验证已授权的真实链路**。在隔离 Linux 资产上验证 Web SSH、发布和恢复。记录执行前状态、授权范围、结果与回退。
3. **按需推进 AI 告警分析**。沿用现有模型服务、诊断证据和审批。用户确认此项后，再做从告警直接分析、显示证据和匹配受控动作的入口。
4. **测量容量与部署恢复**。在隔离样本测队列、并发、指标查询与资源消耗，补齐容器重启、备份恢复和证书更新验收。

每项改动先写目标、涉及文件、兼容性、失败与回退、验收命令。完成后更新当前基线和 [验收记录](VERIFICATION_AND_RELEASE.md)。
